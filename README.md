# 리듬 하우스 연습실 예약 시스템

기존 파일을 **덮어쓰는** 새 버전입니다. Firebase 프로젝트(`rhythm-house-cc90c`)와
GitHub 저장소(`artist4rhythm-hub/rhythm-house`)는 그대로 씁니다.

---

## 들어 있는 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 예약 앱 (회원 + 관리자) — 기존 파일 덮어쓰기 |
| `board.html` | 연습실 입구 현황판 — 기존 파일 덮어쓰기 |
| `logo.png` | 로고 (배경 투명) — 새 파일 |
| `icon-192.png` `icon-512.png` | 앱 아이콘 |
| `manifest.json` `sw.js` | 홈 화면 설치용 |
| `firestore.rules` | 보안 규칙 (업로드하지 말고, 아래 3번처럼 콘솔에 붙여넣기) |

---

## 설치 순서

### 1. 파일 올리기

GitHub 저장소 → **Add file → Upload files** 에서
`firestore.rules`와 `README.md`를 뺀 **나머지 전부**를 한 번에 올립니다.
같은 이름은 자동으로 덮어쓰기 됩니다.

### 2. 구글 로그인 켜기 (최초 1회)

Firebase 콘솔 → **Authentication → Sign-in method**

1. **Google** 을 켜고 저장합니다. (지원 이메일은 본인 주소를 고르면 됩니다)
2. **이메일/비밀번호** 는 **사용 중지**로 둡니다.
   켜두면 누구나 남의 주소로 계정을 만들 수 있어 위험합니다.
3. 같은 화면 아래 **승인된 도메인**에 `artist4rhythm-hub.github.io` 가 있는지 확인하고,
   없으면 **도메인 추가**로 넣습니다. 이게 없으면 구글 로그인 창이 거부됩니다.

예전에 만들어 둔 비밀번호 계정이 있다면 **Authentication → 사용자** 에서 모두 지웁니다.
같은 주소로 구글 로그인을 하면 충돌이 날 수 있습니다.

### 3. 보안 규칙 붙여넣기

Firebase 콘솔 → **Firestore Database → 규칙** 으로 가서
기존 내용을 모두 지우고 `firestore.rules` 파일 내용을 전부 붙여넣은 뒤 **게시**를 누릅니다.

### 4. 관리자 명단 올리기 (최초 1회)

Firebase 콘솔 → **Firestore Database → 데이터**
`members` 컬렉션에 문서를 하나 만듭니다.

**문서 ID = 본인 구글 주소를 소문자로** (예: `artist4rhythm@gmail.com`)

| 필드 | 유형 | 값 |
|---|---|---|
| `name` | 문자열 | 이현우 |
| `email` | 문자열 | artist4rhythm@gmail.com |
| `role` | 문자열 | **admin** |
| `active` | 부울 | true |

네 개면 충분합니다. 나머지는 앱이 알아서 채웁니다.

> 예전 버전에서 만든 **UID 이름의 문서는 지우세요.** 이제 쓰지 않습니다.

### 5. 들어가 보기

사이트에서 **Google 계정으로 로그인**을 누르고 그 주소로 들어가면 관리자 화면이 열립니다.

---

## 로그인은 이렇게 됩니다

비밀번호가 없습니다. **관리자가 명단에 올린 구글 주소**로 들어온 사람만 통과합니다.

1. 회원이 쓰는 구글 주소(Gmail)를 알려줍니다
2. 관리자가 **회원** 탭에서 그 주소로 등록합니다
3. 회원은 사이트에서 **Google 계정으로 로그인**만 누르면 끝입니다

명단에 없는 주소로 들어오면 "명단에 없는 주소입니다" 화면이 뜨고,
그 주소를 복사해 관리자에게 보낼 수 있습니다. 등록해 주면 바로 들어옵니다.

회원을 명단에서 지우면 그 주소로는 더 이상 로그인할 수 없습니다.
비밀번호를 바꾸거나 잊어버릴 일이 없습니다.

## 운영하는 법

### 회원 등록

관리자 → **회원** 탭 → **＋ 회원 추가**
이름·연락처·**구글 주소**·레슨 요일과 시각을 넣고 저장합니다.
비밀번호는 만들지 않습니다. 저장하면 전달할 안내문이 뜹니다.

> 구글 주소는 반드시 **그분이 실제로 쓰는 계정**이어야 합니다.
> 오타가 있으면 로그인했을 때 명단에 없다고 나옵니다. 그때는 주소만 고치면 됩니다.

### 회원 상세 — 회원 목록에서 이름을 누르면 열립니다

한 사람에 대한 모든 것이 한 화면에 있습니다.

- 연락처 · **카카오톡 프로필 링크** · **학부모 이름/연락처** · 구글 주소 · 기본 레슨 일정
- **메모** — 진도, 성향, 주의할 점을 자유롭게
- **이번 달 레슨 n / 4회** — 회차마다 날짜·시각이 나오고 눌러서 고칠 수 있습니다
- **레슨비** — 이번 달 입금 확인 켜고 끄기
- **연습권** — 남은 시간, 소멸일, 이번 주기 사용량
- **예약 현황** — 다가오는 예약과 지난 기록, 여기서 바로 취소

이 항목들은 **설정** 버튼에서 입력합니다. 월 레슨 횟수도 회원마다 다르게 둘 수 있습니다.

### 레슨 완료 처리

회원 상세 → **레슨 완료 처리**

**날짜와 시각을 직접 넣습니다.** 기본 일정이 있어도 실제로는 조율되는 일이 많기 때문입니다.
가장 가까운 지난 레슨 일정이 기본값으로 들어오니 보통은 그대로 저장하면 됩니다.

**연습권도 함께 지급**은 기본으로 켜져 있습니다.
기록만 남기고 연습권은 주지 않으려면 체크를 풀면 됩니다.
지급할 시간은 지난 주기에 얼마나 썼는지 보고 자동으로 계산됩니다.

이미 남긴 기록은 목록에서 **수정**을 눌러 날짜·시각을 고치거나 지울 수 있습니다.
기록을 지워도 이미 지급한 연습권은 그대로 남습니다.

### 회원 화면에 자동으로 이어집니다

관리자가 **레슨으로 잡기**로 연습실을 선점하면, 그 회원의 홈 화면에
**다음 레슨**으로 날짜·시각·연습실이 바로 뜹니다. 따로 알릴 필요가 없습니다.

회원 홈에는 이것들이 함께 보입니다.

- 다음 레슨 일정
- **이번 달 레슨 n / 4회** 와 진행 막대
- 이번 달 레슨비 입금 여부
- 남은 연습권과 예약한 연습 목록

**내 정보** 탭에는 레슨 기록과 지난 연습이 쌓입니다.

### 연습실 잡기 · 레슨 일정 · 시간 닫기

관리자는 **현황** 탭의 타임라인 빈 칸, 또는 **예약** 탭의 빈 시간을 누르면
아래 네 가지를 고를 수 있습니다.

| 고르기 | 쓰임 | 회원 화면에 보이는 모습 |
|---|---|---|
| **내가 사용 · 연습** | 본인이 연습실을 쓸 때 | 예약 완료 |
| **회원 예약** | 전화·대면으로 받은 예약을 대신 넣을 때 | 예약 완료 |
| **레슨으로 잡기** | 레슨 시간을 미리 선점할 때 | 레슨 (금색) |
| **이 시간 닫기** | 심야나 점검 등으로 받지 않을 때 | 사용 불가 (점선) |

관리자가 넣은 예약과 레슨은 **연습권이 차감되지 않습니다.**
레슨은 회원을 고르면 그 회원의 일정으로, 고르지 않으면 이름 없이 잡힙니다.

### 회원끼리는 서로를 볼 수 없습니다

예약 문서에 **회원 이름을 저장하지 않습니다.** 저장되는 것은 내부 식별자뿐이고,
회원은 다른 회원의 정보를 읽을 권한이 없습니다.
회원 화면에서는 **막힌 이유를 구분하지 않습니다.**
남의 예약이든 남의 레슨이든 운영자가 닫아둔 시간이든 모두 똑같이 **사용 불가**로만 보입니다.
남의 레슨이 '레슨'으로 보이면 자기 레슨으로 오해하기 쉽기 때문입니다.

회원 화면에 쓰이는 표시는 네 가지뿐입니다.

| 표시 | 뜻 |
|---|---|
| 가능 | 지금 예약할 수 있음 |
| 내 예약 (빨강) | 내가 잡은 연습 — 눌러서 취소 |
| 내 레슨 (금색) | 내 레슨 시간 |
| 사용 불가 (어두움) | 이미 찬 시간 — 이유는 묻지도 보이지도 않음 |

관리자 화면에서는 예전처럼 **이름 · 레슨 · 닫은 시간**이 그대로 다 보입니다.
이름은 **관리자 화면에서만** 회원 목록을 통해 찾아서 보여줍니다.
입구 현황판도 이름 없이 **연습 중 / 레슨 중 / 사용 불가**만 띄웁니다.

### 주간 한눈에

**예약** 탭과 **현황** 탭 위쪽에서 **날짜별 / 주간 한눈에** 를 고를 수 있습니다.
주간 보기는 가로 7일 × 세로 24시간이고, 한 칸 안의
**왼쪽 막대가 블랙룸 · 오른쪽 막대가 화이트룸**입니다.
칸이나 날짜를 누르면 그날의 날짜별 화면으로 넘어갑니다.

### 입구 현황판

연습실 입구 모니터 브라우저에서 `.../board.html` 을 열고 **한 번만 로그인**합니다.
이후에는 자동으로 유지되며, 예약이 생기면 즉시 반영됩니다. F11로 전체화면을 권합니다.

화면은 세 칸으로 나뉩니다.

1. **지금 상태** — 연습실마다 사용 중 / 레슨 중 / 비어 있음과 남은 시간
2. **오늘 시간표** — 연습실마다 24시간 막대
3. **이번 주** — 월요일부터 7일, 날마다 두 줄 (위 블랙룸 · 아래 화이트룸)

### 끝나기 5분 전 안내

**바로 다음 시간에 예약이 있을 때만** 종료 5분 전부터 안내가 뜹니다.
입구 현황판에는 빨간 띠로, 회원 앱 홈 화면에는 안내 카드로 보입니다.
뒤에 아무도 없으면 띄우지 않습니다.

### 화면 크기

폰은 한 줄, 태블릿 가로는 두 배, PC는 세 배 폭으로 자동으로 넓어집니다.
홈 화면에 설치해 전체화면으로 열어도 폰의 시계·배터리 표시줄과 홈 바를 비켜갑니다.

## 연습권 규칙

- 레슨을 마치면 연습권이 지급되고 **7일 뒤 소멸**됩니다 (이월 없음).
- 예약은 **1회 1시간**씩, 원하는 만큼 나눠서 할 수 있습니다.
- **주 3시간**으로 시작합니다.
- 받은 시간을 **다 채우면 다음 주 5시간**으로 늘어납니다.
- **주 5시간을 4주 연속** 다 채우면 그 다음부터 **기본이 주 5시간으로 확정**됩니다.
- 한 주에 **3시간 미만**으로 쓰면 다시 **주 3시간**으로 돌아갑니다.

## 예약 규칙

- 연습실 **블랙룸 · 화이트룸** 2개, **24시간** 운영
- 예약은 **누르면 바로 확정**됩니다 (승인 대기 없음)
- **예약 시작 3시간 전까지** 취소할 수 있고, 취소하면 연습권이 돌아옵니다
- 3시간 이내에는 취소·변경할 수 없습니다

## 데이터가 담기는 모양

| 컬렉션 | 문서 이름 | 들어 있는 것 |
|---|---|---|
| `members` | **소문자 구글 주소** | 이름·연락처·역할·연습권·레슨 일정 |
| `bookings` | `블랙룸_2026-10-05_19` | 연습실·날짜·시각·`memberId`·종류 |
| `lessons` | 자동 | 레슨 완료 기록 |

예약에는 이름도 이메일도 들어가지 않습니다. 뜻 없는 식별자(`mid`)만 들어가고,
회원은 남의 회원 문서를 읽을 권한이 없어서 그 식별자가 누구인지 알 수 없습니다.

---

## 중복 예약이 생기지 않는 이유

예약 문서의 이름을 `블랙룸_2026-10-05_19` 처럼 **연습실·날짜·시간으로 고정**했습니다.
한 연습실의 한 시간에는 문서가 하나만 존재할 수 있고,
보안 규칙에서 **덮어쓰기를 막아** 두었습니다.

두 사람이 같은 순간에 같은 시간을 눌러도 **먼저 도착한 쪽만 저장**되고,
다른 쪽에는 "방금 다른 분이 예약했어요"가 뜹니다.
