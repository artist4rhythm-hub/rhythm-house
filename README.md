# 리듬 하우스 연습실 예약 시스템

기존 파일을 **덮어쓰는** 새 버전입니다. Firebase 프로젝트(`rhythm-house-cc90c`)와
GitHub 저장소(`artist4rhythm-hub/rhythm-house`)는 그대로 씁니다.

---

## 들어 있는 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 예약 앱 (회원 + 관리자) — 기존 파일 덮어쓰기 |
| `board.html` | 연습실 입구 현황판 — 기존 파일 덮어쓰기 |
| `logo.png` | 로고 (배경 투명) — 새 파일 |
| `icon-192.png` `icon-512.png` | 앱 아이콘 |
| `manifest.json` `sw.js` | 홈 화면 설치용 |
| `firestore.rules` | 보안 규칙 (업로드하지 말고, 아래 3번처럼 콘솔에 붙여넣기) |

---

## 설치 순서

### 1. 파일 올리기

GitHub 저장소 → **Add file → Upload files** 에서
`firestore.rules`와 `README.md`를 뺀 **나머지 전부**를 한 번에 올립니다.
같은 이름은 자동으로 덮어쓰기 됩니다.

### 2. 예전 연습실 데이터는 그대로 두세요

새 버전은 `members` · `bookings` · `lessons` 세 컬렉션만 씁니다.
기존 `users` · `reservations` 등은 건드리지 않으니 그대로 두셔도 되고,
나중에 정리하셔도 됩니다.

### 3. 보안 규칙 붙여넣기

Firebase 콘솔 → **Firestore Database → 규칙** 으로 가서
기존 내용을 모두 지우고 `firestore.rules` 파일 내용을 전부 붙여넣은 뒤 **게시**를 누릅니다.

### 4. 관리자 계정 만들기 (최초 1회)

**4-1.** Firebase 콘솔 → **Authentication → 사용자 → 사용자 추가**
본인 이메일과 비밀번호를 넣고 추가합니다.

**4-2.** 사이트에 접속해 그 이메일·비밀번호로 로그인합니다.
"아직 등록되지 않은 계정이에요" 화면이 나오면서 **UID**가 보입니다. **UID 복사**를 누르세요.

**4-3.** Firebase 콘솔 → **Firestore Database → 데이터**
`members` 컬렉션을 만들고(이미 있으면 문서 추가), **문서 ID에 복사한 UID**를 붙여넣은 뒤
아래 필드를 입력합니다.

| 필드 | 유형 | 값 |
|---|---|---|
| `name` | 문자열 | 이현우 |
| `email` | 문자열 | (본인 이메일) |
| `role` | 문자열 | **admin** |
| `active` | 부울 | true |
| `credits` | 숫자 | 0 |
| `weeklyHours` | 숫자 | 3 |
| `usedThisCycle` | 숫자 | 0 |
| `baseHours` | 숫자 | 3 |
| `fullStreak` | 숫자 | 0 |
| `cycles` | 숫자 | 0 |

**4-4.** 앱에서 로그아웃했다가 다시 로그인하면 관리자 화면이 열립니다.

> 이 작업은 처음 한 번만 합니다. 이후 회원은 앱 안에서 바로 등록할 수 있습니다.

## 운영하는 법

### 회원 등록

관리자 → **회원** 탭 → **＋ 회원 추가**
이름·연락처·이메일·임시 비밀번호·레슨 요일과 시각을 넣고 저장합니다.
등록이 끝나면 전달할 안내문이 뜹니다. 그 내용과 사이트 주소를 학부모에게 보내면 됩니다.

> 회원을 추가해도 **관리자 로그인은 풀리지 않습니다.**

### 레슨 후 연습권 지급

레슨을 마치면 관리자 → **회원** 탭 → 그 회원의 **레슨 완료 · 연습권 지급**을 누릅니다.
지난 주기에 얼마나 썼는지 보고 **이번에 몇 시간을 줄지 자동으로 계산**해서 알려줍니다.

### 연습실 잡기 · 레슨 일정 · 시간 닫기

관리자는 **현황** 탭의 타임라인 빈 칸, 또는 **예약** 탭의 빈 시간을 누르면
아래 네 가지를 고를 수 있습니다.

| 고르기 | 쓰임 | 회원 화면에 보이는 모습 |
|---|---|---|
| **내가 사용 · 연습** | 본인이 연습실을 쓸 때 | 예약 완료 |
| **회원 예약** | 전화·대면으로 받은 예약을 대신 넣을 때 | 예약 완료 |
| **레슨으로 잡기** | 레슨 시간을 미리 선점할 때 | 레슨 (금색) |
| **이 시간 닫기** | 심야나 점검 등으로 받지 않을 때 | 사용 불가 (점선) |

관리자가 넣은 예약과 레슨은 **연습권이 차감되지 않습니다.**
레슨은 회원을 고르면 그 회원의 일정으로, 고르지 않으면 이름 없이 잡힙니다.

### 회원끼리는 서로를 볼 수 없습니다

예약 문서에 **회원 이름을 저장하지 않습니다.** 저장되는 것은 내부 식별자뿐이고,
회원은 다른 회원의 정보를 읽을 권한이 없습니다.
그래서 회원 화면에는 **예약 완료 / 레슨 / 사용 불가**만 보이고,
누른 사람에게는 "이미 예약된 시간이에요" 안내가 뜹니다.
이름은 **관리자 화면에서만** 회원 목록을 통해 찾아서 보여줍니다.
입구 현황판도 이름 없이 **연습 중 / 레슨 중 / 사용 불가**만 띄웁니다.

### 입구 현황판

연습실 입구 모니터 브라우저에서 `.../board.html` 을 열고 **한 번만 로그인**합니다.
이후에는 자동으로 유지되며, 예약이 생기면 즉시 반영됩니다. F11로 전체화면을 권합니다.

## 연습권 규칙

- 레슨을 마치면 연습권이 지급되고 **7일 뒤 소멸**됩니다 (이월 없음).
- 예약은 **1회 1시간**씩, 원하는 만큼 나눠서 할 수 있습니다.
- **주 3시간**으로 시작합니다.
- 받은 시간을 **다 채우면 다음 주 5시간**으로 늘어납니다.
- **주 5시간을 4주 연속** 다 채우면 그 다음부터 **기본이 주 5시간으로 확정**됩니다.
- 한 주에 **3시간 미만**으로 쓰면 다시 **주 3시간**으로 돌아갑니다.

## 예약 규칙

- 연습실 **블랙룸 · 화이트룸** 2개, **24시간** 운영
- 예약은 **누르면 바로 확정**됩니다 (승인 대기 없음)
- **예약 시작 3시간 전까지** 취소할 수 있고, 취소하면 연습권이 돌아옵니다
- 3시간 이내에는 취소·변경할 수 없습니다

## 중복 예약이 생기지 않는 이유

예약 문서의 이름을 `블랙룸_2026-10-05_19` 처럼 **연습실·날짜·시간으로 고정**했습니다.
한 연습실의 한 시간에는 문서가 하나만 존재할 수 있고,
보안 규칙에서 **덮어쓰기를 막아** 두었습니다.

두 사람이 같은 순간에 같은 시간을 눌러도 **먼저 도착한 쪽만 저장**되고,
다른 쪽에는 "방금 다른 분이 예약했어요"가 뜹니다.
